# Red-Team Prompt

Review the AWS Biopharma static dashboard for teammate review.

Ask:

- What can fail in the dashboard render path?
- What is unsupported by committed evidence?
- What claim wording overreaches beyond reproducible evidence workflow or
  repurposing hypothesis?
- What data should not be extracted, committed, or displayed?
- What missing adapter, provider token, or external service is being laundered
  as PASS?
- What Merkle, FCO, custody, or release proof is absent?
- What would make this unsafe to ingest, publish, push, or share with a
  teammate?

Hard rails:

- Use only supplied local repo evidence.
- Do not request, print, infer, or expose secrets.
- Treat missing optional provider tokens as `not_configured`, not PASS.
- Treat the OpenAI red-team status as generated by the current run.
- Return blockers only when teammate review would be prevented, a secret would
  leak, the dashboard would fail to render, or claim/data-rights limits would
  be violated.
